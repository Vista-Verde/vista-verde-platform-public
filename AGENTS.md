# Public snapshot contributor guidance

Preserve explicit consent, verified identity, object-level authorization, transaction/idempotency and synthetic-data boundaries. Do not deploy, handle real payments, control machinery, or publish private records without separate authorization. Owner-access and backup settings are example placeholders, not usable production credentials/configuration.

Run applicable type, lint and test checks. Report commands actually run and limitations. Keep the license-pending notice until the repository owner explicitly chooses a license. Never infer a platform-wide license from dependency notices.
