# Public snapshot scope

This repository starts with one clean root commit rather than inherited development history. Private founder context, planning journals, historical validation evidence, deployment records and original repository metadata are omitted. Real owner-access identifiers and backup-drive identity have been replaced by example placeholders. The original private project is not deployed or modified by this publication.

Source checks are not proof of absence of every secret or vulnerability. This snapshot is experimental and may need further configuration and review. Review dependency licenses in `package-lock.json` and their upstream packages before redistribution. The original platform code in this public repository is licensed under the [Apache License, Version 2.0](LICENSE). This does not license or publish the private repository.

Do not publish credentials, personal information, private customer records, or real machine/payment configuration in issues or pull requests.

## Historical compatibility limitation

The frozen legacy runtime, its original commit and legacy-image compatibility jobs are intentionally excluded. `local:*`, legacy image builds and restore/compatibility suites are not supported end-to-end by this public snapshot. Core source demos and source-level checks remain included; a separately reviewed portable deployment path is future work.
